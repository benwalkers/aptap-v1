`.pytest_cache/`, `models/minilm/`, and `.DS_Store`. It was **not modified**.
Those rules cover the known large local artefacts. Ignore status was assessed from
these simple literal rules; `git check-ignore`/`git ls-files` cannot establish index

release credential file was found, and runtime SQLite currently resides under ignored
`work/`. Optional future defence: add `.env*` with an intentional example-file exception,
private-key/credential patterns as appropriate, and `*.sqlite*`/`*.db*` if such files
can appear outside `work/`. Review exact exceptions before adopting broad patterns.
These are recommendations, not changes made in this phase.
